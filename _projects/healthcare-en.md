## Overview
**Healthcare (守护天使)** is a team-built mobile application developed through undergraduate software engineering and a campus software innovation competition. It explores how an accessible mobile interface can bring health information, medicine lookup, and health-monitoring features into one place, with older adults as an important user group.

## System architecture
The application follows a client–server design: an **Android client using MVVM** communicates with **Java Spring Boot backend services**, which handle application logic and persistent data. API definitions and Swagger documentation support coordination between frontend and backend development.

Building the application required connecting user-facing screens with service interfaces and data access, then checking the complete interaction flow. The public repository preserves the client–server implementation and project materials.

## My contribution
I worked as a **team organizer and backend developer**, contributing to software design, service implementation, and integration. My responsibilities included translating feature requirements into backend interfaces, coordinating interface changes with teammates, and helping keep implementation aligned with the project schedule.

The development process included requirements analysis, interface prototypes, UML design, Git-based collaboration, feature testing, and bug fixing. This gave me practical experience with the full path from a proposed user feature to a working application flow.

## Outcome and demonstration
The project produced an application prototype and a recorded team demonstration. It received a **Second Prize in Fuzhou University's software innovation competition**. The source-code button above links to the HealthCare V2 repository corresponding to the Android and Spring Boot system shown here.
