## Overview
This ongoing research investigates an agentic pipeline for extracting, organizing, and retrieving reusable assets from enterprise code repositories. It extends my interest in agents and structured environments to software systems.

## Research questions
How should repository-level context be represented and retrieved? Which pieces of context improve completion beyond the current file? How can reusable software assets be organized so that an agent can find and use them?

## Current work
Since July 2026, I have been investigating repository-level retrieval and code completion on **RepoBench** and **CodeScaleBench**, comparing **UnixCoder**, **RepoHyper**, and **RepoSkein** to study the contribution of repository context.

The pipeline links asset extraction, structured organization, and retrieval for downstream code tasks. This project is ongoing; results will be added as the research develops.
