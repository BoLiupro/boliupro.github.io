

## Homepage previews and project demos

The homepage draws four horizontal preview rows directly from the shared content data. Project `short_title` fields provide compact card headings while detail pages retain the full titles. YouTube demos use `youtube_id` in `_data/projects.yml`; the same ID powers the project-detail player and the Projects demo gallery. The sidebar channel URL is in `_data/profile.yml`. Publication anonymous-code buttons use the optional `anonymous` field.
